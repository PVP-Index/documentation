# Forum

The PvPIndex forum is a place to discuss strategy, post highlight clips, swap server recommendations, and report bugs. It's at:

```
pvpindex.com/forum
```

You need a website account to post (see [Creating an account](/user/creating-an-account)). Reading is open to everyone.

## Boards

The forum is organised into **boards**. Each board has its own rules pinned at the top - read those before you post.

Typical boards:

| Board | What goes here |
| --- | --- |
| Announcements | Read-only - official updates from the PvPIndex team. |
| General | Anything PvPIndex-related that doesn't fit the other boards. |
| Strategy & Guides | Game-mode-specific tips, kit theory-crafting, write-ups. |
| Highlights | Clips, screenshots, "watch this dispute" links. |
| Server recommendations | Players asking for and recommending verified servers. |
| Bug reports | Report a website or plugin bug. Include reproduction steps. |
| Feedback | Suggest features for the website or the plugin. |

The exact list of boards is maintained by the admin team and may differ from the table above.

## Posting

1. Open a board.
2. Click **New post** in the top right.
3. Write your title and body. The editor supports markdown - fenced code blocks, inline code, links, images.
4. Submit.

Posts are visible to everyone immediately. There is no pre-moderation queue.

## Replies

Click any post to read it and reply. Replies appear in chronological order. Quote-replies are supported (highlight any text in the parent post, then click the **quote** button).

## Reactions

You can leave a single reaction per post or comment (👍 / 👎 / ❤️ / 😄). Reactions are public - others can see who left them.

## Moderation

Anything you post can be reported with the flag icon on the post or comment. Moderators review reports and may hide content that violates the board rules (see [Moderating on the website](/server_mod/moderating-on-the-website) for the moderator side of this).

## Bumping

There is **no** bump mechanic - the boards sort by **last reply** by default, so a fresh comment naturally moves a thread to the top. Posting "bump" with no content adds no value and may be hidden.

## Direct messages

Click any user's avatar in the forum to **Send DM**. DMs are private to the two participants. You can disable DMs from your privacy settings (see [Your profile](/user/your-profile)).
